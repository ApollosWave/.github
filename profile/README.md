# ApollosWave

### An independent software studio. Small, calm, and built to last.

We believe software should be quiet, capable, and respectful of your time. No bloated dependencies, no endless loading spinners, and no predatory subscriptions for basic utilities. Just focused tools engineered with care.

---

### How We Build

* **Zero Bloat**: Fast software begins with fewer moving parts. We favor pure standard libraries, lean single-file executables, and minimal dependencies.
* **Ownership Over Rent**: We build tools that run locally on your machine, under your control, with zero vendor lock-in.
* **Craftsmanship Over Scale**: We are deliberately small. We prioritize depth, speed, and polish over growth at all costs.

---

### Software & Open Source

* **[GSC CLI](https://github.com/ApollosWave/gsc-cli)** — A zero-gem, lightning-fast SEO intelligence engine and AI agent skill for Google Search Console, Google Indexing, Core Web Vitals, and keyword research.
* **[PackingLog](https://packinglog.com)** — Smart QR-code moving box inventory organizer with 1-tap photo cataloging and printable label sheets.
* **[Superspeed](https://superspeedapp.com)** — Autonomous Core Web Vitals and website speed optimization engine for modern web apps.
* **[Supercart](https://supercartapp.com)** — High-converting, distraction-free slide cart drawer and upsells for Shopify merchants.
